# Английский через истории · Telegram Publisher

Готовый Telegram-публикатор для первого и второго сезонов курса.

## Зафиксированные параметры

- Канал: `@english_story_a1a2`
- Часовой пояс: `Europe/Moscow`
- Сезон 1: 1–30 сентября 2026 года
- Сезон 2: 1–31 октября 2026 года
- Утренний урок: 07:00, окно повторов до 09:00
- Дневная практика: 12:00, окно повторов до 14:00
- Итоговые Quiz Poll: 14:00 последнего дня сезона
- Поздравление: 16:00 последнего дня сезона

## Что добавлено для сезона 2

- 31 утренний урок и 31 дневная практика;
- 53 MP3: 31 утренний, 21 дневной и 1 файл финального аудиозадания;
- 5 изображений: недели 1–4 и финал сезона;
- 38 Quiz Poll: 31 ежедневный и 7 финальных;
- финальный документ публикаций;
- расписание GitHub Actions на октябрь 2026 года;
- отдельные идентификаторы `s2_*`, поэтому публикации не конфликтуют с сезоном 1.

## Секреты GitHub

Используются те же Secrets, которые уже настроены для первого сезона:

- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`

Создавать новые Secrets для второго сезона не нужно.

## Как обновить существующий репозиторий

1. Распакуйте ZIP на компьютере.
2. Откройте существующий GitHub-репозиторий курса.
3. Нажмите `Add file → Upload files`.
4. Перетащите **содержимое** распакованной папки, а не саму внешнюю папку.
5. Убедитесь, что в списке есть `.github/workflows`, `audio/season2`, `content/season2.json`, `images/season2` и `publisher.py`.
6. Внизу страницы выберите `Commit directly to the main branch`.
7. Нажмите `Commit changes`.

Загрузка обновит технические файлы, но не очищает `state/published.json` и не удаляет материалы первого сезона.

## Как самостоятельно заменить изображения сезона 1

Замените файлы, сохранив их точные имена и расположение:

```text
images/week01.png
images/week02.png
images/week03.png
images/week04.png
images/final.png
```

После загрузки новых изображений откройте `Actions → Refresh English Course Assets`, нажмите `Run workflow`, введите `REFRESH` и дождитесь зелёной галочки. Workflow автоматически обновит контрольные суммы и сохранит их в репозитории. Изображения сезона 2 находятся в `images/season2` и при этом не меняются.

## Проверка после загрузки

1. Откройте вкладку `Actions`.
2. Выберите `Publish English Course`.
3. Нажмите `Run workflow`.
4. Выберите режим `preview`.
5. Запустите workflow.
6. Ожидаемый результат — зелёная галочка и сообщение теста:

```text
Package QA passed: 2 seasons, 126 events, 314 Telegram steps, 105 audio, 10 images, 75 polls
```

## Визуальный предпросмотр второго сезона в Telegram

Workflow `Preview English Course` отправляет настоящие тестовые публикации, но не меняет `state/published.json`.

1. Откройте `Actions → Preview English Course`.
2. Нажмите `Run workflow`.
3. Выберите событие, например `s2_day01_morning`.
4. В поле `confirm` введите `PREVIEW`.
5. Запустите workflow.
6. Проверьте публикацию в Telegram и удалите тестовые сообщения вручную.

Для полной проверки удобно последовательно запустить:

- `s2_day01_morning` — обычный утренний пост и аудио;
- `s2_day01_practice` — дневной пост, аудио и Quiz Poll;
- `s2_day07_morning` — фото, пост и аудио недельного повторения;
- `s2_day31_morning` — финальный длинный диалог;
- `season2_final_polls` — семь итоговых заданий;
- `season2_congratulations` — финальное фото и поздравительный пост.

## Совместимость аудио с Telegram

Если на некоторых устройствах MP3 воспроизводится только 1–2 секунды:

1. Откройте `Actions → Repair English Course Audio`.
2. Нажмите `Run workflow`.
3. В поле `confirm` введите `REPAIR`.
4. Запустите workflow и дождитесь зелёной галочки.

Workflow перекодирует все MP3 обоих сезонов в совместимый формат и автоматически обновит SHA-256 в `season1.json` и `season2.json`.

## Порядок публикаций

- обычный утренний урок: пост → аудио;
- утренний урок с фото: фото → пост → аудио;
- дневная практика с аудио: пост → аудио → Quiz Poll;
- дневная практика без аудио: пост → Quiz Poll;
- финальное поздравление: фото → пост.

## Ручная аварийная публикация

В `Actions → Publish English Course → Run workflow` выберите `event`, укажите точный `event_id` и введите `PUBLISH`.

Пример для второго сезона:

```text
event_id: s2_day01_morning
confirm: PUBLISH
```

Этот режим является настоящей публикацией и обновляет `state/published.json`. Для обычной визуальной проверки используйте только `Preview English Course`.

## Локальная проверка

```bash

```

Публикатор дополнительно ограничен точными датами 2026 года и не повторит сезоны автоматически в следующем году.
