# Английский через истории — сезоны 1–4

## Установка обновления

1. Распакуйте English_Course_Update_S2_S3_S4.zip на компьютере.
2. Загрузите содержимое в корень существующего репозитория с сохранением путей.
3. Обязательно обновите .github/workflows (папка может быть скрыта).
4. Замените одноимённые файлы. Не удаляйте остальные файлы репозитория.
5. Не заменяйте и не очищайте state/published.json: его нет в архиве обновления.
6. Запустите Actions → Publish English Course → action: check.
   Проверка проверяет пакет и доступ бота, но не публикует уроки.

Не загружайте сам ZIP вместо распакованных файлов.
При загрузке частями сначала добавьте медиа и source, затем одновременно
content, scripts, tests, publisher.py и .github/workflows.
Не оставляйте обновление незавершённым.

## Расписание (Europe/Moscow)

- Сезон 1: сентябрь 2026, 30 дней. Без новых бонусов.
- Сезон 2: октябрь 2026, 31 день.
- Сезон 3: ноябрь 2026, 30 дней.
- Сезон 4: декабрь 2026, 31 день.
- Утро: 07:00, окно повторных попыток до 09:00.
- Практика: 12:00, окно до 14:00.
- Бонусы сезонов 2–4: дни 7, 14, 21, 28 в 18:00, окно до 20:00.
- Итоговые опросы: в последний день в 14:00, поздравление — в 16:00.

Интервал в расписании workflow — 5 минут в указанных окнах.
Это не гарантия запуска GitHub ровно в назначенную минуту.
Завершённые шаги учитываются в state/published.json.

## Ручная публикация

Actions → Publish English Course → Run workflow:

- action: check, welcome, morning, practice, bonus, final_polls, congratulations, start_button;
- publication: official — публикация с сохранением состояния;
- day: номер дня; 0 — текущий день месяца;
- season: 1–4; 0 — определить по месяцу 2026 года.

Для bonus выбирайте сезон 2–4 и день 7, 14, 21 или 28.
ВНИМАНИЕ: test тоже отправляет сообщения в настроенный канал, но не записывает
состояние. Последующая official-публикация может повторить их.
Preview English Course также отправляет реальный предпросмотр в канал.

Secrets TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID остаются прежними.
Не записывайте токены в файлы.
