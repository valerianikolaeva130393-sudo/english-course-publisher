# Английский через истории · Telegram Publisher

Готовый Telegram-публикатор для первых трёх сезонов курса.

## Зафиксированные параметры

- Канал: `@english_story_a1a2`
- Часовой пояс: `Europe/Moscow`
- Приветственный пост: 31 августа 2026 года в 18:00, окно повторов до 20:00
- Сезон 1: 1–30 сентября 2026 года
- Сезон 2: 1–31 октября 2026 года
- Сезон 3: 1–30 ноября 2026 года
- Утренний урок: 07:00, окно повторов до 09:00
- Дневная практика: 12:00, окно повторов до 14:00
- Итоговые Quiz Poll: 14:00 последнего дня сезона
- Поздравление: 16:00 последнего дня сезона

## Что добавлено для сезона 3

- 30 утренних уроков и 30 дневных практик;
- 52 MP3: 30 утренних, 21 дневной и 1 файл финального аудиозадания;
- 5 изображений: недели 1–4 и финал сезона;
- 37 Quiz Poll: 30 ежедневных и 7 финальных;
- финальный документ публикаций;
- расписание GitHub Actions на ноябрь 2026 года;
- отдельные идентификаторы `s3_*`, поэтому публикации не конфликтуют с сезонами 1 и 2.

## Секреты GitHub

Используются те же Secrets, которые уже настроены:

- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`

Создавать новые Secrets для третьего сезона не нужно.

Бот должен иметь права публиковать, редактировать и закреплять сообщения в канале.

## Автоматический запуск курса

- 31 августа в 18:00 публикуется `images/welcome.png` с короткой подписью;
- приветственный пост автоматически закрепляется;
- 1 сентября после выхода текста и аудио Дня 1 к закреплённому посту добавляется кнопка `🚀 Начать с Дня 1`;
- кнопка ведёт непосредственно на утренний урок первого дня;
- предпросмотр `course_welcome` отправляет только фото с подписью, не закрепляет его и не изменяет состояние публикаций.

## Как обновить существующий репозиторий

1. Распакуйте ZIP на компьютере.
2. Откройте существующий GitHub-репозиторий курса.
3. Нажмите `Add file → Upload files`.
4. Перетащите **содержимое** распакованной папки, а не саму внешнюю папку.
5. Убедитесь, что в списке есть `.github/workflows`, `audio/season3`, `content/season3.json`, `images/season3` и `publisher.py`.
6. Внизу страницы выберите `Commit directly to the main branch`.
7. Нажмите `Commit changes`.

Загрузка обновит технические файлы, но не очищает `state/published.json` и не удаляет материалы первых двух сезонов.

## Проверка после загрузки

1. Откройте вкладку `Actions`.
2. Выберите `Publish English Course`.
3. Нажмите `Run workflow`.
4. Выберите режим `preview`.
5. Запустите workflow.
6. Ожидаемый результат — зелёная галочка и сообщение:

```text
Package QA passed: launch + 3 seasons, 190 events, 472 Telegram steps, 157 audio, 16 images, 112 polls
```

## Визуальный предпросмотр третьего сезона в Telegram

Workflow `Preview English Course` отправляет настоящие тестовые публикации, но не меняет `state/published.json`.

1. Откройте `Actions → Preview English Course`.
2. Нажмите `Run workflow`.
3. Выберите событие.
4. В поле `confirm` введите `PREVIEW`.
5. Запустите workflow.
6. Проверьте публикацию в Telegram и удалите тестовые сообщения вручную.

Для полной проверки удобно последовательно запустить:

- `course_welcome` — приветственное изображение и подпись без закрепления;
- `s3_day01_morning` — обычный утренний пост и аудио;
- `s3_day01_practice` — дневной пост, аудио и Quiz Poll;
- `s3_day07_morning` — фото, пост и аудио недельного повторения;
- `s3_day30_morning` — финальный длинный диалог;
- `season3_final_polls` — семь итоговых заданий;
- `season3_congratulations` — финальное фото и поздравительный пост.

## Совместимость аудио с Telegram

Все 52 MP3 третьего сезона уже перекодированы в совместимый формат. Если после будущей замены файлов аудио на некоторых устройствах воспроизводится только 1–2 секунды:

1. Откройте `Actions → Repair English Course Audio`.
2. Нажмите `Run workflow`.
3. В поле `confirm` введите `REPAIR`.
4. Запустите workflow и дождитесь зелёной галочки.

Workflow проверит MP3 трёх сезонов и автоматически обновит SHA-256 в `season1.json`, `season2.json` и `season3.json`.

## Порядок публикаций

- обычный утренний урок: пост → аудио;
- утренний урок с фото: фото → пост → аудио;
- дневная практика с аудио: пост → аудио → Quiz Poll;
- дневная практика без аудио: пост → Quiz Poll;
- финальное поздравление: фото → пост.

## Ручная аварийная публикация

В `Actions → Publish English Course → Run workflow` выберите `event`, укажите точный `event_id` и введите `PUBLISH`.

Пример:

```text
event_id: s3_day01_morning
confirm: PUBLISH
```

Этот режим является настоящей публикацией и обновляет `state/published.json`. Для обычной визуальной проверки используйте только `Preview English Course`.

## Локальная проверка

```bash
python tests/test_package.py
```

Публикатор ограничен точными датами 2026 года и не повторит сезоны автоматически в следующем году.
